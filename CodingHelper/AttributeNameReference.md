# Attribute name reference

[中文版](AttributeNameReference_zh-cn.md)

Note:

- The generated fields (for data class) or properties (for view model class) have attribute names 
that follow the name patterns in the third column.

  To be compatible with the INP interface, extra fields / properties will also be generated, 
with their attribute names following the name patterns in the fourth column.

- In the patterns, "**\<Id>**" is used to identify the object, defined by the programmer, 
use as-is for the third column, and use it in PascalCase for the second column. 

  "**\<Number>**" corresponds to the definition order of "**\<Id>**", starting from 1, 
automatically generated by the generator.

- Objects or object properties that are **bolded** are not real objects or properties in the OpenAPI, 
the way to create them depends on the programmer.

- Object properties that are ***bolded and italicized*** are not always used, it depends on the situation.

- Object properties that are marked with an asterisk\* depend on the OpenAPI version.
